Titre H2  : "Questions fréquentes sur le développement d'applications web"
Questions :
  Q1 (H3) : "Quelle différence entre un site web et une application web ?"
  R  : Un site présente de l'information. Une application web permet d'agir : gérer commandes, suivre stocks, analyser données. C'est un outil de travail, pas une vitrine.

  Q2 (H3) : "Combien coûte une application web sur mesure ?"
  R  : À partir de 800 000 FCFA pour un MVP. Application web complète : 2M à 8M FCFA selon la complexité. Devis gratuit après premier échange.
  Lien interne : → /tarifs

  Q3 (H3) : "L'application web sera accessible sur mobile ?"
  R  : Oui, responsive par défaut. Si vous avez besoin d'offline ou de push natif, on recommande une application mobile dédiée.
  Lien interne : → /services/developpement-mobile

  Q4 (H3) : "Peut-on connecter l'app à notre ERP ou CRM ?"
  R  : Oui. Intégrations API sur mesure vers SAP, Odoo, Salesforce, HubSpot ou tout outil avec une API.

  Q5 (H3) : "Quel est le délai de développement ?"
  R  : MVP application web en 4-6 semaines. App complète : 2-4 mois. Sprints validés ensemble.

  Q6 (H3) : "Formation des utilisateurs incluse ?"
